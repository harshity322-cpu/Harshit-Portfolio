# Harshit Yadav — Portfolio

> Personal portfolio website showcasing my projects, skills, and experience as a Full Stack Developer.

**Live Site:** [harshityadav.dev](https://harshityadav.dev)

---

## Features

- **Animated Particle Background** — Interactive canvas-based particle network
- **Typing Effect** — Dynamic role text animation in the hero section
- **Custom Cursor** — Smooth cursor dot + ring follower
- **Virtual Pet** — Interactive cat companion with fish, yarn, and sleep states
- **Scroll Reveal Animations** — IntersectionObserver-powered element animations
- **Project Filtering** — Filter projects by category (Full Stack / Frontend)
- **Skill Progress Bars** — Animated skill level indicators
- **Counter Animation** — Auto-counting stats on scroll
- **Tilt Effect** — 3D perspective tilt on project cards
- **Magnetic Buttons** — Hover-follow effect on buttons
- **Contact Form** — Functional contact form with validation
- **Fully Responsive** — Optimized for mobile, tablet, and desktop

## Getting Started

No build step required — it's a static site.

```bash
# Clone the repository
git clone https://github.com/harshity322-cpu/harshit-portfolio.git

# Open in browser
cd harshit-portfolio
open index.html
```

Or use Live Server in VS Code for the best experience.
